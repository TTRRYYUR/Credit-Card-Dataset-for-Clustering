# Credit-Card-Dataset-for-Clustering

Учебный проект по кластеризации клиентов на основе поведения владельцев кредитных карт: покупок, платежей, баланса и снятия наличных.

Я сравнил четыре алгоритма — KMeans, Agglomerative Clustering, DBSCAN и Gaussian Mixture — и посмотрел, какие группы клиентов они выделяют. В этом запуске лучший результат среди моделей, которые умеют относить новых клиентов к кластерам, показал **KMeans** с Silhouette Score **0,4120**.

## Данные

В проекте используется датасет [Credit Card Dataset for Clustering на Kaggle](https://www.kaggle.com/datasets/arjunbhasin2013/ccdata).

Он содержит данные примерно о 9 000 клиентах. Среди признаков — баланс кредитной карты, покупки, снятие наличных, кредитный лимит, платежи и частота операций.

`CUST_ID` используется как идентификатор и исключается перед обучением. Остальные 17 исходных признаков — числовые.

## Подготовка признаков

Помимо исходных данных я добавил несколько отношений, которые помогают описать поведение клиента:

- отношение баланса к частоте его обновления;
- долю разовых покупок в общей сумме покупок;
- среднюю сумму покупки;
- отношение баланса к кредитному лимиту;
- покупки в месяц.

При делении на ноль получившееся отношение заменяется нулём. Это допущение стоит учитывать при интерпретации результатов.

Далее признаки проходят обработку внутри pipeline:

1. Пропуски заполняются медианными значениями.
2. Для части признаков применяется `log1p`, чтобы уменьшить влияние больших значений.
3. Признаки масштабируются с помощью `RobustScaler`.
4. К логарифмируемой группе применяется PCA с тремя компонентами. Признаки частоты обрабатываются отдельно.
5. Подготовленные данные передаются модели кластеризации.

## Сравнение моделей

Для каждой модели перебираются заданные комбинации параметров. Качество разбиения оценивается с помощью **Silhouette Score**: чем выше значение, тем лучше в среднем объекты отделены от соседних кластеров в используемом пространстве признаков.

Результаты этого запуска:

| Модель | Silhouette Score | Что получилось |
|---|---:|---|
| **KMeans** | **0,4120** | Три кластера; лучшая модель с поддержкой `predict` |
| Agglomerative Clustering | 0,4010 | Три кластера с похожими профилями |
| Gaussian Mixture | 0,3618 | Четыре кластера, включая группу с выраженным снятием наличных |
| DBSCAN | 0,2018 | Несколько плотных групп и часть клиентов, отмеченная как шум |

Для DBSCAN объекты с меткой `-1` исключаются из расчёта силуэта. Поэтому его оценка рассчитана на подмножестве данных и напрямую сравнивать её с оценками остальных моделей нужно осторожно.

## Результаты KMeans

KMeans разделил клиентов на три группы. В таблице приведены медианные значения признаков внутри каждого кластера:

| Кластер | Баланс | Покупки | Снятие наличных | Кредитный лимит | Платежи |
|---|---:|---:|---:|---:|---:|
| 0 | 91,03 | 928,53 | 0,00 | 4 000 | 1 095,92 |
| 1 | 1 389,59 | 340,00 | 244,60 | 3 000 | 930,85 |
| 2 | 25,38 | 133,35 | 0,00 | 2 700 | 338,57 |

**Кластер 0** отличается более высокими покупками и платежами при сравнительно небольшом балансе.

**Кластер 1** — самая большая группа на графике. У неё выше медианный баланс, а также заметно снятие наличных.

**Кластер 2** характеризуется более низкими медианными покупками, балансом и платежами.

Эти описания основаны на медианах: они помогают сравнить группы, но не описывают каждого клиента внутри них. Номера кластеров условны и могут измениться при повторном обучении.

## Что показали другие модели

### Agglomerative Clustering

Модель выделила три группы с профилями, похожими на группы KMeans: клиентов с более высокими покупками, группу с более высоким балансом и группу с низкой активностью. При этом размеры и границы кластеров отличаются. Само по себе сходство профилей ещё не доказывает устойчивость сегментов — для этого нужна отдельная проверка.

### Gaussian Mixture

Gaussian Mixture выделил четыре группы. В одной из них медианные покупки равны нулю, а медианная сумма снятия наличных составляет примерно **1 250**. Такой профиль может быть полезной отправной точкой для дальнейшего исследования поведения клиентов.

### DBSCAN

DBSCAN нашёл две крупные группы, несколько небольших кластеров и клиентов, которых алгоритм отнёс к шуму. На графике количество шума заметно: около 1 700 клиентов.

Небольшие группы интересны для изучения, но их размер и устойчивость нужно проверить отдельно, прежде чем делать выводы о поведении или риске клиентов. Метка `-1` означает шум по правилам DBSCAN, а не установленную аномалию.

## Визуализация

Для каждой модели строятся:

- двумерная PCA-проекция кластеров;
- график количества клиентов в кластерах;
- график медианных значений основных признаков по кластерам.

На PCA-графиках можно увидеть общую форму и пересечения групп. Это двумерная проекция подготовленных данных, поэтому по ней нельзя полностью судить о разделении кластеров в пространстве, где обучалась модель.

## Запуск

Для запуска нужны Python и зависимости из `requirements.txt`:

```bash
pip install -r requirements.txt
```

Скачайте датасет по ссылке выше и поместите файл `CC GENERAL.csv` в папку проекта. Затем запустите:

```bash
python main.py
```

Программа обучит модели, выведет оценки и профили кластеров, а также откроет графики. Их нужно закрывать по очереди, чтобы выполнение продолжилось.

Лучшая по силуэту модель с поддержкой `predict` сохраняется в `model.pkl`. В показанном запуске это **KMeans**. DBSCAN и Agglomerative Clustering участвуют в исследовании, но не сохраняются для предсказания новых клиентов, поскольку не поддерживают такой способ прогноза.

## Структура проекта


## Ограничения и дальнейшая работа

Silhouette Score помогает оценить геометрию кластеров, но не измеряет их практическую ценность. Профили дают гипотезы для исследования, а не готовые выводы о платёжной дисциплине или кредитном риске.

Для продолжения работы можно проверить устойчивость кластеров на разных подвыборках, изучить распределения признаков внутри групп и сравнить результаты с другой подготовкой данных.
